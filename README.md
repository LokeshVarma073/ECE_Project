# Login Page 🔐

A simple and responsive **Login Page** built as a frontend web development project.
This project focuses on creating a clean user interface with a modern design and basic login form elements.

## ✨ Features

* 📧 Email / Username input
* 🔒 Password input
* 👁️ Password visibility option
* ☑️ Remember Me option
* 🔑 Forgot Password link
* 🚪 Login button
* 📝 Sign Up / Register option
* 📱 Responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
Login-Page/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/LokeshVarma073/ECE_Project.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! 🎉
